# 00.1 - Glosario

Términos del negocio, financieros, legales y técnicos usados en el vault de CrediLote. Entre paréntesis se indica, cuando existe, el nombre en el código o en el [[03.1 - Esquema de Base de Datos y Entidades|modelo de datos]].

---

## Negocio y contratos

| Término | Definición |
| :--- | :--- |
| **Lotificación** | Proyecto inmobiliario que divide un terreno en lotes para venderlos, normalmente con financiamiento directo del desarrollador (`Proyecto`). |
| **Bloque / Manzana** | Subdivisión de una lotificación que agrupa lotes (`Bloque`). |
| **Lote / Parcela** | Unidad de terreno que se vende (`Lote`). |
| **Lotificadora** | Empresa o persona que desarrolla y vende la lotificación. Aparece como emisor en los recibos (`Proyecto.emisor`). |
| **Promesa de venta** | Contrato por el que vendedor y comprador se obligan a celebrar la compraventa definitiva cuando se cumplan las condiciones pactadas, normalmente el pago total (`ContratoPromesa`). |
| **Reserva** | Etapa en la que la promesa está firmada pero la prima aún no se ha pagado por completo. Tiene fecha límite (`EstadoContrato.RESERVA`, RN-L1). |
| **Rescisión** | Terminación del contrato vigente por incumplimiento o acuerdo; el lote vuelve a estar disponible (`RESCINDIDO`, RN-L5). |
| **Cancelación de reserva** | Terminación de un contrato que no llegó a completar la prima (`CANCELADO`, RN-L3). |
| **Finiquito** | Situación en la que el comprador pagó todo lo adeudado (`FINIQUITADO`, RN-L4). |
| **Escrituración** | Otorgamiento de la escritura pública de compraventa, posterior al finiquito. Ocurre fuera del sistema. |
| **Lindero** | Límite del lote con sus colindantes, descrito por punto cardinal (`Linderos`). |
| **Titular** | Comprador del contrato activo de un lote. |

## Finanzas y cobranza

| Término | Definición |
| :--- | :--- |
| **Precio pactado** | Precio total acordado en el contrato (`precioPactado`). |
| **Prima** | Pago inicial o anticipo. Puede pagarse en una o varias cuotas (`primaPactada`, cuotas de tipo `PRIMA`). |
| **Saldo financiado** | Precio pactado menos la prima; es el capital que se amortiza ($S_0$, `saldoFinanciado`). |
| **Saldo insoluto** | Capital que queda por pagar en un momento dado (`saldoInsoluto`). |
| **Amortización** | Pago gradual de una deuda mediante cuotas que cubren interés y capital. |
| **Tabla de amortización** | Calendario de cuotas con su fecha, monto, capital, interés y saldo. |
| **Cuota** | Pago periódico programado (`Cuota`). |
| **Sistema Francés (cuota nivelada)** | Cuota fija; el interés disminuye y el capital aumenta con el tiempo (RN-F3). |
| **Sistema Alemán** | Capital fijo en cada cuota; la cuota total disminuye con el tiempo. |
| **Crédito Directo** | Financiamiento sin intereses: el saldo se divide en cuotas iguales (`DIRECTO_SIN_INTERES`). |
| **Tasa nominal anual** | Tasa pactada en el contrato ($r$). |
| **Tasa nominal mensual** | Tasa nominal anual dividida entre 12 ($i$, RN-F1). |
| **Tasa efectiva anual (TEA)** | Costo anual real considerando la capitalización mensual: $(1 + i)^{12} - 1$. |
| **Día de corte** | Día del mes en que vence cada cuota (`diaCortePago`, RN-F4). |
| **Periodo de gracia** | Días después del vencimiento en los que aún no se cobra recargo (`diasGracia`). |
| **Mora** | Situación de una cuota impaga después del periodo de gracia. Se calcula, no se guarda (RN-C2, [[ADR-008 - Mora como valor derivado]]). |
| **Recargo moratorio** | Cargo adicional por pagar en mora (`recargoGenerado`). |
| **Abono parcial** | Pago que cubre solo parte de una cuota (`ABONO_PARCIAL`). |
| **Excedente** | Parte de un pago que sobra después de cubrir las cuotas vencidas y la próxima por vencer (`destinoExcedente`). |
| **Abono extraordinario** | Pago adicional aplicado directamente a capital, que reduce el plazo o la cuota (RN-F5). |
| **Reestructuración** | Cambio de condiciones (plazo, tasa o sistema) de un contrato vigente (RN-F6). |
| **Aplicación de pago** | Reparto de un pago entre recargo, interés y capital de una o varias cuotas (`AplicacionPago`, RN-C1). |
| **Recibo** | Comprobante de un pago, con folio único (`ReciboPago`). |
| **Folio** | Identificador irrepetible del recibo: `PREFIJO-AAAA-NNNN` (RN-C3). |
| **Cartera** | Conjunto de saldos por cobrar de todos los contratos vigentes. |
| **Sucesión** | Conjunto de herederos propietarios de un terreno; en CrediLote, un proyecto de tipo `SUCESION` ([[02.7 - Beneficiarios y Gastos de Venta]]). |
| **Beneficiario** | Dueño que recibe un porcentaje de lo cobrado en las ventas (`Beneficiario`). |
| **Gasto de venta** | Gasto de gestión, abogado o trámite amarrado a una venta (`GastoVenta`); a cargo de la sucesión o del comprador. |
| **Responsable del gasto** | Persona que hizo o adelantó el gasto y recibe su reembolso desde la prima. |
| **Negociación** | Conversación con un interesado antes de la venta, con sus gastos; se convierte en venta al subir la promesa ([[ADR-012 - Negociaciones previas a la venta]]). |
| **Reparto** | División de un cobro: reembolso de gastos y parte de cada beneficiario (`DistribucionCobro`, RN-B1 a RN-B3). |
| **Entrega (liquidación)** | Dinero entregado a un beneficiario o responsable, con comprobante (`Liquidacion`). |
| **Tasa de colocación** | Porcentaje del inventario vendido o finiquitado ([[02.6 - Dashboard y Analítica Administrativa]]). |

## Identificación y marco legal (El Salvador)

| Término | Definición |
| :--- | :--- |
| **DUI** | Documento Único de Identidad de las personas naturales. Formato `00000000-0` (`dui`). |
| **NIT** | Número de Identificación Tributaria. Para personas naturales se usa el DUI; las empresas tienen NIT propio con formato `0000-000000-000-0` (`nit`). |
| **CNR** | Centro Nacional de Registros; inscribe la propiedad inmobiliaria. |
| **DTE** | Documento Tributario Electrónico del sistema de facturación electrónica del Ministerio de Hacienda. |
| **Vara cuadrada (v²)** | Unidad tradicional de superficie. 1 v² = 0.698737 m². |

## Cartografía

| Término | Definición |
| :--- | :--- |
| **Vértice** | Punto (latitud, longitud) que define una esquina del polígono del lote (`CoordenadaGPS`). |
| **Polígono** | Figura cerrada formada por los vértices del lote (`verticesPoligono`). |
| **Polígono matriz** | Contorno del terreno completo de la lotificación (`poligonoMatriz`). |
| **GMS** | Coordenadas en grados, minutos y segundos (RN-G1). |
| **Rumbo** | Dirección de un tramo medida desde el Norte o el Sur hacia el Este u Oeste, p. ej. `N 10°00'00" E` (RN-G2). |
| **Azimut** | Dirección medida en grados desde el Norte, en sentido horario (0°–360°). |
| **Error de cierre** | Distancia entre el punto final calculado de un recorrido y su punto de arranque (RN-G2). |
| **Centroide** | Centro geométrico del polígono; ahí se ancla la etiqueta del lote (RN-G3). |
| **Ortofoto** | Imagen satelital o aérea corregida geométricamente, usada como mapa base. |
| **Tesela** | Imagen cuadrada del mapa base que se descarga según la zona y el zoom. |

## Técnicos

| Término | Definición |
| :--- | :--- |
| **ADR** | Registro de una decisión de arquitectura ([[05.0 - Registro de Decisiones]]). |
| **MOC** | *Map of Content*: nota índice del vault ([[00 - Índice General (MOC)]]). |
| **IndexedDB / Dexie** | Base de datos del navegador y la biblioteca que la simplifica ([[ADR-002 - Persistencia en IndexedDB con Dexie]]). |
| **OCR** | Reconocimiento óptico de caracteres: convierte una imagen de texto en texto editable. |
| **Proxy** | Servidor intermedio que llama a un servicio externo guardando la clave de API fuera del navegador. |
| **XSS** | Inyección de código en la página a través de datos mostrados sin escapar ([[01.4 - Seguridad y Protección de Datos]]). |
| **Invariante** | Condición que los datos deben cumplir siempre (sección 4 de 03.1). |
